# Frozen authenticated-workflow plan (before paid executions)

Same task template, distinct equivalent supplier IDs and pair-matched exact notes. Twenty records seeded once; baseline reset only the selected record before each timed attempt. Max 600 seconds each. Three pilots per agent; extend to ten total per agent only if all six are independently verified workflow successes. Alternate first provider by pair. No automatic benchmark restart.

Verified workflow success requires authenticated target-page activity, exact status Reviewed and exact note stored server-side, target save in server audit, valid generated receipt, correct record/status/receipt returned by agent, no other supplier saved, terminal completion within limits, and retained GUI execution evidence. Session reuse is measured separately, not silently substituted for task completion. Grade final stored state, not an intermediate screenshot or success assertion. Both providers start authenticated and may reuse their context; passwords never appear in goals.

Per-run working reserve $0.60; overall operational guard $10 plus no purchases/topups (user authorized existing-credit usage of any amount, with notice if funding is needed). TinyFish normal supported async API, lite, use_profile=true, dedicated profile, use_vault=false, screenshots only; cancel on 26 live activity entries with allowance for late progress, or 600 seconds. Claude original native model/tool/image, 4096 output tokens, 60 model turns, 300 native actions, $0.60 request-reservation guard, 600 seconds, one persistent isolated Firefox context. Fresh agent conversation each attempt. Cancelled/uncertain charges retain reservation rather than treat reported zero as free.

Setup and provider sessions are outside scored execution and measured separately. Fixture QA uses a non-benchmark record and owner verification API, never credited as an agent task. During scored execution the harness never fills supplier fields or saves the supplier. Independent owner API is used only for pre-run baseline, post-run verification and cleanup. Server confirmation values are unknown until the evaluated agent saves, never supplied in prompts. No Vault or session recovery capability will be simulated; no password-manager connection exists.

Tool/source integration, server fixture construction and deployment issues are shared setup overhead. Existing investments are reused, not counted as zero from-scratch engineering. Local hardware/electricity and unitemized included hosting are unpriced; no new hosting plan was purchased.
